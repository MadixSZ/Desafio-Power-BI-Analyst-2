## Funcionalidades Implementadas

Neste projeto foram aplicados os seguintes conceitos técnicos:

* **Navegação Interativa**: Botões configurados para alternar de forma fluida entre as duas páginas do relatório.
* **Filtros e Segmentadores**: Segmentadores de dados configurados para filtrar as informações por período de datas, otimizando a análise de lucros e vendas.
* **Indicadores (Bookmarks)**: Utilização avançada de indicadores associados a botões, permitindo alternar a exibição de visuais diferentes sobre o mesmo assunto no mesmo painel (ex: Gráfico de Barras vs. Gráfico de Tarte).
* **Identidade Visual**: Criação de um layout estruturado, aplicando um tema personalizado com tons escuros e destaques em rosa.

## Como Executar Localmente

Caso pretenda inspecionar a modelagem de dados ou a estrutura do relatório:

1. Faça o download do ficheiro `.pbix` disponível neste repositório.
2. Abra o ficheiro utilizando o **Microsoft Power BI Desktop**.
3. Navegue livremente pelas abas e explore as funcionalidades criadas.
